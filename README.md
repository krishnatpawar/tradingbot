# sectrot — Sector Momentum Rotation

A monthly-rebalanced momentum rotation strategy over 11 SPDR sector ETFs,
backtested on 2010-01 → 2026-10 total-return data with transaction costs.

## Strategy rules (fixed a priori, no parameter fitting)

- **Universe:** XLF, XLK, XLE, XLV, XLI, XLP, XLU, XLY, XLB, XLRE, XLC
- **Signal:** 126-trading-day (~6-month) total return, measured at month-end
- **Position:** equal-weight top-3 sectors by momentum, rebalanced monthly
- **Regime filter (variant):** if SPY closes below its 200-day MA, hold cash
- **Execution:** trades at month-end close (implementable via market-on-close orders)
- **Costs:** 5 bps one-way on notional traded

## Backtest results (2010-01 → 2026-10, data through 2026-10-15)

| Strategy | CAGR | Avg/mo | Months ≥5% | Sharpe | Max DD |
|---|---|---|---|---|---|
| momentum-only | 12.2% | 1.04% | 12.9% | 0.92 | −31.4% |
| momentum + 200DMA filter | 7.5% | 0.66% | 7.9% | 0.67 | −38.7% |
| SPY buy-and-hold (benchmark) | 14.1% | 1.19% | 15.8% | 0.99 | −33.7% |

2020+ sub-period (out-of-sample consistency check): momentum-only CAGR 12.9%,
Sharpe 0.80 — no collapse, but still trails SPY.

**Honest verdict:** neither variant comes close to 5%/month (which compounds to
~80%/year — a return no audited public track record sustains). The regime
filter hurt more than it helped (whipsaw). Momentum-only is a reasonable
~12%/yr strategy with equity-like risk, not a 5%/month machine.

## Files

- `strategy.py` — strategy definition + backtester (run: `python strategy.py`)
- `download_yahoo.py` — data fetcher (Yahoo v8 chart API via curl; yfinance is
  blocked in some sandboxes). Validated: SPY 2024 total return = 24.9% ≈ the
  established ~25.0%.
- `prices.parquet` — daily dividend/split-adjusted closes (regenerated by the fetcher)
- `results.json` — full metrics; `equity_curve.csv` — strategy vs SPY equity

## Paper trading (live forward test)

`paper_trader.py` runs the strategy against a virtual **$100,000** account at
real market closes — no broker, no real money. It recomputes the latest
month-end signal from fresh data, rebalances only when the target changes,
charges the same 5 bps cost as the backtest, and logs every trade.

- `paper_state.json` — current cash/positions/target
- `paper_log.csv` — append-only trade + equity-mark audit trail
